# 硬件采购清单

> 中文 · [English](hardware-shopping-list.md)

面向 M1 无线麦克风节点，以及可选的 M2 路由器救援方案。价格为人民币，反映 2026 年
淘宝的典型报价；下单前请自行核对，价格会浮动。

## M1 必需（约 110–150 元）

| 物品 | 选型要点 | 大致价格 | 备注 |
|---|---|---|---|
| ESP32-S3 开发板 | DevKitC-1 N16R8（16MB Flash，8MB PSRAM） | 55–80 | N8 版本也可以；关键是要带 PSRAM，用于音频缓冲。不要买没有 S3 的裸 ESP32——它的 I2S 麦克风驱动很折腾。 |
| INMP441 I2S MEMS 麦克风 | 直插模块，6 针（VDD/GND/L/R/WS/SCK/SD） | 7–12 | 除非你享受焊 0.65mm 焊盘，否则挑已经焊好排针的版本。 |
| 杜邦线 | 母对母，20cm | 5 | 一包够做十来个项目。 |
| USB-C 数据线 | 必须能传数据（不能是只充电的） | 也许你已有？ | 只充电的线会导致「设备未识别」——确认你的线能传数据。 |
| 小面包板 | 400 孔或半尺寸 | 8–15 | 打算直接焊就不用买。 |

**小计：约 75–120 元**

### 购买渠道

- **淘宝**：搜「ESP32-S3-DevKitC-1 N16R8」和「INMP441 模块」。挑销量 >2000、评分 ≥4.9
  的卖家；杂牌小店的克隆板有时会装错 USB 转串口芯片。
- **嘉立创商城（lcsc.com）**：乐鑫官方模块，价格略高，发货快，无假货风险。
- **AliExpress**：仅当你在中国境外时考虑；国内发货比淘宝慢。

### 避坑要点

1. **开发板上有两个 USB 口**。用标着 **UART** 的那个，不是 USB 那个。USB 口能走原生
   USB，但 PlatformIO 默认的烧录流程走的是 UART 上的 CP210x/CH340。
2. **PSRAM 编译标志**。本仓库的 `platformio.ini` 已设好 `-DBOARD_HAS_PSRAM` 和缓存
   修复标志——别删掉它们，否则音频缓冲会悄悄丢帧。
3. **麦克风 L/R 引脚**。把 INMP441 的 L/R 接到 GND（左声道）。接到 VDD 会变成只有
   右声道，固件从左槽读到的就全是零。
4. **供电**。USB 给板子加麦克风够用。如果你的笔记本口只有 500mA，别再用同一路 USB
   带喇叭——改用带供电的 HUB 或加个电源适配器。

## 可选：本地 TTS 播放（约 15–30 元）

除非你想让 ESP32 在不开浏览器的情况下也能「说话」，否则跳过。中枢已经能通过看板
播放 TTS。

| 物品 | 规格 | 大致价格 |
|---|---|---|
| MAX98357A I2S DAC + 功放模块 | 3W D 类，单声道 | 10–15 |
| 4Ω 3W 喇叭 | 40mm 盆径 | 5–10 |
| 额外杜邦线 | — | — |

把 MAX98357A 接到第二个 I2S 口（`I2S_NUM_1`），再把 MP3 解码出的 PCM TTS 帧推进去。
当前固件忽略了 `tts_audio` 数据——等你备齐硬件后再补上播放路径。

## 可选：M2（路由器自愈）

如果你手上没有跑 OpenWrt 的路由器，最省钱的路子是翻出一台退役的来改造。买新的前先确认：

- **已经在跑 OpenWrt？** 那就齐了。确保已开启 SSH
  （`uci set dropbear.@dropbear[0].PasswordAuth='on'`），或把你的 SSH 公钥拷到
  `/etc/dropbear/authorized_keys`。
- **GL.iNet 旅行路由器**（GL-MT300N-V2、GL-AR300M16）：出厂自带 OpenWrt，新的约
  150–250 元，二手约 80–120 元。最省事。
- **小米 AX3000T / 红米 AX6000**：有官方 OpenWrt 构建，但刷机需要先解锁；除非你
  喜欢折腾，否则不推荐。
- **TP-Link Archer C7 v5**：支持得很好的老牌目标，但只能买二手——TP-Link 锁死了
  新固件。

仓库里的 `OpenWRTRouter` 适配器假设是原版 OpenWrt 的 SSH。如果你用 ImmortalWrt 或
某个厂商分支，`reboot` 和 `wifi reload` 命令通常一样——可用
`ssh root@router /sbin/wifi --help` 确认。

## 你「不需要」的东西

- 额外的 WiFi 模块。ESP32-S3 自带 2.4GHz。
- 专用音频编解码芯片。INMP441 直接输出 24 位 I2S，固件在软件里降到 int16——便宜，
  16kHz 下够用。
- 唤醒词专用芯片。ESP-SR 能跑在同一颗 S3 上。等其余管线稳定后再接。
- 树莓派。中枢跑在你现有的 PC 上。只有当你想让它常开、又不想一直开着 PC 时，才加一台 Pi。

## 下单前自检

```
- [ ] ESP32-S3-DevKitC-1，带 PSRAM（N8R8 或 N16R8）
- [ ] INMP441 模块，排针已预焊
- [ ] 母对母杜邦线，至少 6 根
- [ ] 一根你之前验证过能传数据的 USB-C 线
```

这些就足够把 M1 端到端跑通。喇叭和 OpenWrt 路由器等 M1 真正跑起来再说——
调试期间保持物料清单精简，是最快的路径。
